# 3xMoha

I’m interested in machine learning systems, backend engineering,
and the infrastructure that connects them.

I learn by building: implementing neural networks from scratch,
working with computer vision pipelines, and developing APIs with
an emphasis on correctness and reproducibility.

### Projects

- [Semantic Platform API](https://github.com/3xMoha/semantic-platform-api)
  — A service operations backend built with TypeScript, NestJS,
  and PostgreSQL. Includes technician scheduling, transactional
  work-order completion, and durable invoice events.

- [Perception Data Platform](https://github.com/3xMoha/perception-data-platform)
  — Reproducible object-detection experiments with verified datasets
  and model weights, CPU inference, and traceable run artifacts.

- [RAG Search](https://github.com/3xMoha/RAG_search)
  — Semantic search over local documents, with embedding-based
  retrieval and local language-model answers through Ollama.

- [Neural Networks from Scratch](https://github.com/3xMoha/nn-from-scratch)
  — A NumPy implementation of neural-network layers,
  backpropagation, and training for binary and multiclass tasks.

### Currently exploring

Reliable backend workflows, reproducible ML pipelines,
and the fundamentals behind model training and inference.
